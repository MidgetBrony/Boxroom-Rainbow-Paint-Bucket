# Rainbow Paint Bucket 0.1.11

Initial public BoxMate release.

- Added a selectable Rainbow Paint Bucket material to BOXROOM's Mods catalogue.
- Added BOXROOM's native RGB, HSV and hex color picker on right-click.
- Added persistent named favorite colors with live swatches and trash buttons.
- Added native painting support for walls, ceilings, floors and paintable furniture.
- Added the correct native painting sound and whole-room painting behavior.
- Added a native BOXROOM paint-roller icon tinted to the current color.
- Preserved every painted color through unique native material IDs in room saves.
- Made favorite storage atomic and update-safe, with a backup file.
